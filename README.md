Harbour Lights — a night dockyard heist: steal the objective, then reach the green EXIT unseen. Three levels across a foggy harbour (the Docks, the Warehouse, the Captain's Office) with patrolling guards, amber vision cones, wall-mounted cameras sweeping blue cones, a guard roster, bushes and deep shadow to hide in (E), lamps that betray you, sneak vs sprint, coin throws to distract, a near-miss readout, an alarm gradient (CALM / UNEASY / HUNTED / ALARM), loot, a ghost bonus, and a timer. An original top-down stealth game in plain JavaScript and Canvas 2D — no libraries, no network requests, all art generated for this game.

## Run it

Serve the game folder with any static server and open `game/index.html`:

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 — WASD to move, Shift to sneak, Space to sprint, E to hide in cover, click (or Q) to throw a coin, Esc to pause, Enter to start.
